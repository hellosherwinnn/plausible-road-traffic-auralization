# Anonymization Notes

The public repository intentionally excludes:

- The thesis PDF and any document containing personal identifiers, matriculation numbers, supervisor names, or unpublished assessment material.
- Raw measurement datasets, informal listening-test spreadsheets, and participant-level responses.
- SPL-derivative analysis notebooks/scripts and listening-test analysis files.
- Generated auralization audio, REAPER peak files, Audacity projects, and large per-frame Pigeon/RAVEN outputs.
- Third-party binaries and toolboxes such as Pigeon executables, RAVEN/ITA Toolbox files, FFmpeg builds, Unreal assets, and Python virtual environments.
- Machine-specific absolute paths, including local Windows drive paths and user-specific download folders.
- Location-specific 3D assets unless they are already public and licensed for redistribution.

The retained files describe the workflow, provide small synthetic examples, and expose reusable code structure for future work.
